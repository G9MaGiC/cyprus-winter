# Cyprus Winter — Ideal Customer Profiles (ICPs)

**Version:** 1.0  
**Date:** March 2026  
**References:** PRD.md, MESSAGING.md, UX_PERSONA.md

---

## Overview

Ideal Customer Profiles define *who* uses Cyprus Winter and *why*—from the user's perspective. ICPs guide product decisions, messaging, discovery flows, and priority. Tone and positioning follow UX_PERSONA.md: understated, Mediterranean, discovery-first.

---

## Primary ICPs (Tourists)

### ICP 1: Cultural Explorer Claire

**Profile:** UK, 48, couple/empty nester. "We've done the beach holidays. Now we want to actually *see* places."

| Dimension | Description |
|-----------|-------------|
| **Motivation** | Escape generic tourism; discover authentic culture; move beyond sun-and-sand; return with "discoverer" status among friends. |
| **Pain points** | Fear of "nothing to do" in winter; overwhelmed by Cyprus's long history; uncertainty whether restaurants/tavernas are open; risk of tourist traps. |
| **Goals** | Visit archaeological sites without heat/crowds; authentic village experiences; moderate hiking; wine culture immersion. |
| **Discovery** | Pre-trip research (BBC Travel, CNT); 6–8 weeks planning; heavy app use 3+ weeks pre-trip; builds detailed 10-day itinerary. |
| **Usage** | Plans 10–14 day stays; books 4–5 guided experiences; shares "Cyprus Wrapped"; reviews 8+ attractions post-trip. |
| **Value proposition** | Real places, real winters. No tourist traps. Curated trails, sites, villages, and wine. |
| **Messaging hook** | *"Real places. Real winters. No tourist traps."* (MESSAGING.md) |
| **Priority** | **Primary** |
| **LTV** | €85 (highest value segment) |

### ICP 2: Active Adventurer Anders

**Profile:** Scandinavia/Germany, 34, solo/partner. "Winter at home is dark and depressing. I want sun on my face while hiking."

| Dimension | Description |
|-----------|-------------|
| **Motivation** | Escape northern winter; combine outdoor activity with sun; complete Troodos trails; photography and challenge. |
| **Pain points** | Unclear trail conditions in winter; limited detailed hiking maps; difficulty finding hiking partners; transport to trailheads without rental car. |
| **Goals** | Complete Troodos trail network; summit Olympus (1,952m) in snow; combine hiking with cultural sites; meet outdoor enthusiasts. |
| **Discovery** | Trail forums, Strava, outdoor blogs; flexible dates, weather-driven; last-minute bookings; searches "Cyprus winter hiking," "Troodos trails January." |
| **Usage** | Daily trail-condition checks; crowd-sourced trail reports; group hikes; shares route photos. |
| **Value proposition** | Troodos trails, winter sun, real-time conditions. Check before you go. |
| **Messaging hook** | *"Troodos trails. Winter sun. Check conditions before you go."* (MESSAGING.md) |
| **Priority** | **Primary** |
| **LTV** | €45 (medium value, high engagement) |

### ICP 3: Digital Nomad Nadia

**Profile:** Poland/Israel/Remote EU, 29, solo. "I can work from anywhere. Why not somewhere warm and affordable?"

| Dimension | Description |
|-----------|-------------|
| **Motivation** | Warm, affordable base; work–life balance; weekend exploration; evaluate Cyprus for return/relocation. |
| **Pain points** | WiFi reliability before booking; isolation; time zone coordination; gym/coworking access. |
| **Goals** | Establish productive routine; weekend exploration; build local network; learn basic Greek. |
| **Discovery** | Nomad List, Facebook groups, coworking reviews; 1–3 month stays; negotiates long-term rates. |
| **Usage** | Weekend planning; nomad meetups; tips for long-stay logistics; refers other nomads (viral growth). |
| **Value proposition** | Work from 16°C. Weekend trails, villages, wine. Community and logistics. |
| **Messaging hook** | *"Work from 16°C. Weekend trails, villages, wine."* (MESSAGING.md) |
| **Priority** | **Primary** |
| **LTV** | €120 (highest retention, 3+ visits/year) |

### ICP 4: Winter Sun Family

**Profile:** UK/Germany, family with young children. "We can't afford summer Cyprus prices, but want outdoor family time."

| Dimension | Description |
|-----------|-------------|
| **Motivation** | Affordable winter escape; outdoor family time; mild weather; educational experiences. |
| **Pain points** | Will attractions hold kids' attention? Weather reliability; baby-changing, stroller access; family-friendly restaurants. |
| **Goals** | Mild weather outdoor activities; educational experiences; beach play without summer crowds; easy logistics; memorable family moments. |
| **Discovery** | Mumsnet, family travel blogs; school-holiday aligned (Christmas, February half-term); 2 weeks pre-trip research. |
| **Usage** | Simple itinerary (2–3 activities/day); "family filter"; shares to closed Facebook groups. |
| **Value proposition** | Mild weather. Beaches, ruins, markets. Family-friendly Cyprus. |
| **Messaging hook** | *"Mild weather. Beaches, ruins, markets. Family-friendly Cyprus."* (MESSAGING.md) |
| **Priority** | **Primary** |
| **LTV** | €60 (seasonal repeat, summer potential) |

## Secondary / Emerging ICPs

### ICP 5: Local Resident / Cypriot

**Profile:** Cyprus resident, any age. Lives on the island year-round; knows many places but seeks seasonal discovery and planning.

| Dimension | Description |
|-----------|-------------|
| **Motivation** | Rediscover home in winter; find weekend ideas; avoid tourist traps; share recommendations with visitors. |
| **Pain points** | Content assumes tourists; few tools for "locals’ favourites"; winter events and openings scattered; difficulty planning weekends with family/friends. |
| **Goals** | Weekend inspiration; trail conditions; seasonal events; reliable, trustworthy recommendations for guests. |
| **Discovery** | Word of mouth; social; direct search for events/trails; app store for "Cyprus winter" or "things to do." |
| **Usage** | Trails, events, seasonal tips; itinerary sharing with visitors; potentially contributes content/reports. |
| **Value proposition** | Your island in winter. Trails, events, villages. Plan weekends and share with visitors. |
| **Messaging hook** | *"Your island in winter. Fewer crowds. Same light."* |
| **Priority** | **Secondary** |
| **LTV** | €15–25 (low direct spend; high advocacy, UGC, ambassador potential) |

**Gap:** No formal ICP for locals in PRD.md or MESSAGING.md. Secondary/Emerging segment.

### ICP 6: Expat Resident

**Profile:** Non-Cypriot living in Cyprus; 6+ months. Familiar with the island but not native; wants to explore beyond default spots.

| Dimension | Description |
|-----------|-------------|
| **Motivation** | Explore beyond usual haunts; feel like a "local"; find authentic, non-touristy options; connect with community. |
| **Pain points** | Tourist content doesn’t match expat needs; limited expat-specific tips; difficulty finding long-stay logistics and community. |
| **Goals** | Weekend exploration; seasonal events; village/taverna recommendations; content to share with visiting friends/family. |
| **Discovery** | Expat forums, Facebook groups; app store; coworking/nomad communities. |
| **Usage** | Similar to locals; event calendars; trails; referral to visiting friends. |
| **Value proposition** | Beyond the usual. Villages, trails, events. Your Cyprus winter. |
| **Messaging hook** | *"Beyond the usual. Villages, trails, events."* |
| **Priority** | **Secondary** |
| **LTV** | €25–40 (moderate; bridges to tourists via referrals) |

---

### ICP 7: Business / Bleisure Traveler

**Profile:** Business traveler (EU/UK); often adds 1–2 days for leisure. Uses Cyprus for meetings, events, or conferences.

| Dimension | Description |
|-----------|-------------|
| **Motivation** | Maximise limited free time; efficient discovery; reliable, quick ideas; avoid wasted trips. |
| **Pain points** | Little time to research; needs short, high-impact plans; airport/transport logistics; uncertain weather and conditions. |
| **Goals** | One or two standout experiences; easy logistics; wine/restaurant recommendations; airport/taxi guidance. |
| **Discovery** | Work trip booking; last-minute search; LinkedIn/travel tools; airport arrivals page. |
| **Usage** | Quick itineraries; airport page; "Just arrived?" CTA; 1–2 curated experiences. |
| **Value proposition** | Limited time? Trails, villages, wine. Curated for short stays. |
| **Messaging hook** | *"Just arrived? One trail. One village. One evening."* |
| **Priority** | **Emerging** |
| **LTV** | €30–50 (per trip; potential repeat if work brings them back) |

## Gaps and Recommendations

### Content & Messaging Gaps

| Gap | Description | Recommendation |
|-----|-------------|----------------|
| **No local/resident ICP** | PRD and MESSAGING.md focus on tourists only. | Add segment hooks and a "Local" / "Expat" section in MESSAGING.md. Consider a "For Residents" or "Your Winter" entry point. |
| **Limited bleisure messaging** | Airport page and "Just arrived?" exist but no dedicated bleisure copy. | Add bleisure-specific meta, headlines, and a short "48 hours" itinerary template. |
| **Family filter** | Winter Sun Family relies on family filter; unclear if implemented. | Confirm family filter in discovery/search; add stroller/accessibility info where relevant. |

### Product Gaps

| Gap | Description | Recommendation |
|-----|-------------|----------------|
| **Local/resident experience** | No distinct flow for residents; all flows assume tourist. | Add optional "I live here" or "Resident mode" to tailor suggestions (fewer basics, more events/weekends). |
| **Expat content** | No expat-specific tips or community links. | Add "For residents & expats" content block; link to nomad/community events. |
| **Bleisure quick-plan** | No 1–2 day itinerary builder. | Add "Short stay" or "48 hours" template; promote on airport page. |
| **Trail conditions** | Core for Anders; depends on crowd-sourced reports. | Ensure trail report UI is prominent and easy; consider Forestry Dept integration. |

### Discovery & Acquisition Gaps

| Gap | Description | Recommendation |
|-----|-------------|----------------|
| **Local acquisition** | No clear path for residents to find the app. | Local SEO ("things to do Cyprus winter"), resident ambassador program, social targeting for Cyprus. |
| **Bleisure acquisition** | Airport page exists but under-promoted. | Promote at LCA/PFO; partner with hotels, conference organisers. |
| **Family acquisition** | Mumsnet, family blogs mentioned but no owned content. | Create family-focused guides; target family travel keywords and communities. |

### Priority Recommendations

1. **P0:** Formalise local/resident ICP in PRD; add segment hooks to MESSAGING.md.  
2. **P1:** Implement or validate family filter; add "Short stay" / bleisure itinerary template.  
3. **P2:** Add resident/exp-related content and optional "Resident mode"; design ambassador programme.
